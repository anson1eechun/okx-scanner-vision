# OKX 研究線負面結果總報告（2026-09-02 → 09-23）

> [!summary] 結論
> 三週、九項研究，涵蓋分鐘級訂單流、技術指標、衍生品情緒因子、突破、日線擇時、纏論、橫截面動能。
> **沒有一項在扣成本後站得住。**
> 兩個反覆出現的事實：
> 1. **BTC 永續在 5 分鐘到 1 小時尺度是均值回歸的**：凡是押延續的都輸，押反轉的又小於成本。
> 2. **每一個「看起來有希望」的結果，都來自小樣本或單一盤勢**，而且放大樣本後全部縮回去。
>
> 這條研究線在 MacBook 上進行，和 anson-pc 的 factor-lab 線互相獨立。factor-lab 的階段總結見 [[2026-06-08 因子研究負面結果總報告]]。

## 反覆出現的事實

### 1. 5 分鐘到 1 小時的均值回歸

同一個現象，從五個互不相干的角度被量到：

| 在哪裡 | 看到什麼 |
|---|---|
| 技術指標 | 15 分鐘 IC 一致為負，約 −0.05 |
| 成交流 | 只有 `ret_5`、`ret_15` 穩健，而且是負的 |
| 訂單流引擎 | 押延續的 FLIP 訊號 48% 命中，平均移動為負 |
| 掃描器 | OI 型態與量能因子方向相反，74 幣中 92–99% 同號 |
| factor-lab 線 | [[05-footprint-CVD研究]] 的 F4 三個窗全負；[[2026-06-08 因子研究負面結果總報告\|族 B 反轉族]] |

**推論：** 在這個尺度押延續一定輸；押反轉在統計上是對的，但效應只有 0.5–2 bps，而成本是 8–12 bps。**這個尺度不值得再測了。**
可能的機制見 [[2009_Bouchaud-Farmer-Lillo_How Markets Slowly Digest Changes in Supply and Demand]]。

### 2. 放大樣本後，每個希望都縮回去

| 最初的希望 | 樣本 | 放大後 |
|---|---|---|
| OI 濾網讓突破 PF 1.19 | 43 筆 | 6 年 74 幣：每筆 −10.5 bp |
| 1H 完整突破 PF 6.95 | 7 筆 | BTC 樣本外 PF 0.86 |
| 訂單流 +8.1R | 1 個趨勢日 | 4 天：−2.4R；扣成本 −151.5R |
| AUCTION_FLIP 85% | 13 次，趨勢日 | 盤整日 50% |
| 橫截面動能 +101% | 33 檔 | 25 檔：−17% |

### 3. 能活下來的線索都在長持有期

- 掃描器因子的 edge 隨持有期單調增加：15m < 1h < 4h
- 深簿失衡的 IC 隨持有期增加
- DBI 的幾何要求持有數小時

這和 [[美元層檢定力上限]] 裡 Arbiter 的建議 (b) 一致：**只打低換手、長持有期的規格。**

### 4. 2024 年後普遍衰退

掃描器的散戶多空比、背離 z 值、±3 總分都在 2021 年最強，2025 年後接近零。

## 這次用上的鑑別器

| 鑑別器 | 攔下了什麼 |
|---|---|
| **先把成本換成 R** | 訂單流引擎：在做任何統計之前，手續費就已經是 2.5R |
| **同曝險的被動基準** | 日線擇時：只做多變體的「alpha」其實是曝險較低 |
| **區塊拔靴取代 iid 打亂** | 日線擇時：iid 打亂讓隨機的 Sharpe 比觀測值還高 |
| **max-t 排列檢定** | 技術指標（證明是真的）、DBI（證明還分不出來） |
| **時間戳對齊驗證** | 掃描器：Binance metrics 在 2024-03-04 換了意思，見 [[05-Binance資料源限制與陷阱]] |
| **按啟動加權 vs 日等權** | 掃描器：持倉比背離的 +5.5 bp 在日等權下是 −0.4 |
| **跨標的廣度** | 掃描器：74 幣同號比例把「BTC 上看起來有效」和「普遍有效」分開 |
| **刻意前視與延後一根** | 纏論：證明全負的結果是訊號問題，不是回測寫錯 |
| **盤勢切分** | 訂單流引擎：把第一天的結論整個反過來 |

## 對照 factor-lab 的「真 alpha 規格」

[[2026-06-08 因子研究負面結果總報告]] 列了七條驗收標準。這九項研究裡，**沒有一項通過第 3 條「扛成本」**。
掃描器的 4''（背離 z 值）通過第 5 條「regime 穩」和第 7 條「多重比較後仍顯著」，是最接近的一個。

## Do-not-revisit（彙總）

- 5 分鐘到 1 小時尺度的任何延續訊號：成交流、delta、CVD、突破、FLIP、價格動能類因子
- 停損 < 50 bps 的分鐘級策略
- BTC 單一資產、只用價格的日線擇時（含纏論買賣點）
- 用絕對 pp 門檻比較大戶與散戶多空比
- 15m 的任何突破 + OI 組合
